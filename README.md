# Huellas-Verdes

Aplicación móvil orientada a la protección de sistemas terrestres.

## Descripción

Huellas Verdes es una plataforma móvil de mapeo colaborativo orientada a la protección de los ecosistemas 
terrestres (ODS 15) en un municipio piloto, diseñada para operar como un canal directo entre la ciudadanía, 
organizaciones no gubernamentales (ONG) y comercios sostenibles, sin intermediación de autoridades gubernamentales 
ni organismos de socorro.
